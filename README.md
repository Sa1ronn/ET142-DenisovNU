# Поиск и первичный анализ наборов данных по различным областям применения

## Описание проекта
Данный репозиторий содержит комплекс программных решений на языке Python для первичного статистического и визуального анализа данных различных типов. Проект выполнен в рамках курсовой работы и демонстрирует полный цикл подготовки сырых данных перед подачей в алгоритмы искусственного интеллекта.

В ходе работы были исследованы четыре фундаментальных типа данных, покрывающих основные индустриальные задачи Data Science.

## Структура проекта и исследуемые наборы данных

### 1. Табличные данные (Классификация банковских транзакций)
* **Файл:** `Chapter_1.ipynb`
* **Задача:** Прогнозирование клиентского оттока на основе транзакционной активности.
* **Стек:** Pandas, NumPy, Seaborn, Matplotlib.
* **Результат:** Проведен анализ баланса классов, обработаны пропуски, удалены полные дубликаты, выявлены ключевые корреляции между финансовыми показателями пользователей.

### 2. Временные ряды (Предиктивная аналитика оборудования)
* **Файл:** `Chapter_2.ipynb`
* **Задача:** Предсказание остаточного полезного ресурса турбовентиляторных авиадвигателей (NASA Turbofan Engine Degradation).
* **Стек:** NymPy, Pandas, Seaborn, Statsmodels.
* **Результат:** Выполнен спектральный анализ деградации сенсоров, сглаживание шума методом скользящего среднего, реализовано ресемплирование сигналов для выделения глобальных трендов износа.

### 3. Изображения (Компьютерное зрение в инфраструктуре)
* **Файл:** `Chapter_3.ipynb`
* **Задача:** Детекция повреждений дорожного покрытия (Potholes Detection).
* **Стек:** OS, PIL, Matplotlib, Glob, Seaborn.
* **Результат:** Написан конвейер строгой алгоритмической фильтрации снимков низкого разрешения, реализован парсинг текстовых аннотаций формата YOLO, осуществлена визуализация ограничивающих прямоугольников поверх исходных фотографий.

### 4. Текстовые данные (Обработка естественного языка)
* **Файл:** `Chapter_4.ipynb`
* **Задача:** Интеллектуальный поиск ответов по корпоративной базе знаний (SberQuAD).
* **Стек:** NumPy, Pandas, Seaborn NLTK, Re, PyMorphy3, Scikit-learn, Collections, WordCloud.
* **Результат:** Реализован полный NLP-конвейер очистки, лемматизации и фильтрации стоп-слов. Построена разреженная матрица признаков TF-IDF. Разработан прототип поискового движка на основе косинусного векторного сходства.
